## 详细讨论

### 问题与想法

#### 1. DVD＋DINO 的效果与 14B 模型上限

用户关注的最终目标是超过 **DA3-GIANT**，而非仅超过无 DINO 分支。该目标属于用户研究期待，尚未实现。

今日讨论确认：

- 14B＋DINO 从 500→1000 步的快速提升没有在所有测试集上持续：1000→1500 步 KITTI 基本持平，NYUv2、DIODE 继续改善。
- 用户决定将资源集中给 **＋DINO 分支独占 16 卡**，从 **1500 步**恢复，学习率调整为 **3e-5**。
- 训练累计上限为 **10000 步**，每 500 步全量评测；10000 步是预算上限，不能视为收敛保证。
- 用户同意保持当前配置继续训练，暂不开展额外性能优化。

训练耗时讨论区分了“单步预测”和“完整训练更新”。约 50 秒／更新包含编码、前向、反向、重计算、梯度累积与通信。不同输入的记录约为：

| 输入 | 完整更新耗时 |
|---|---:|
| VKITTI，9 帧视频 | 64.5 秒 |
| TartanAir，9 帧视频 | 64.0 秒 |
| Hypersim，单图 | 22.6 秒 |

尚无分阶段 profiling，不能确定各模块的准确耗时比例。

#### 2. 二阶段像素监督与解码器改造

需要明确区分两条路线：

- **已完成的联合微调**：更新 DiT LoRA、DINO adapter、Wan VAE decoder，使用逆深度像素 L1＋梯度损失，移除 latent MSE。
- **今日新增的 PiD 消融**：冻结 DVD＋DINO，训练新的 PiD 像素解码网络和 CPM，比较直接深度与残差输出。

前者没有显式保留固定粗深度并叠加修正量，因此不是残差细化实验。DiT 原始权重仍冻结，“放开 DiT”在本实验中具体指训练 **LoRA**。

用户认可 DINO＋pixel loss 组合路线已有价值；这是用户判断。现有实验支持部分测试集改善，尚不足以分离 DINO、decoder 解冻、监督变化和额外训练预算各自的贡献。

#### 3. PiD 解码与直接／残差预测消融

用户提出先获得几何预测，再利用像素网络改善细节。讨论参考了 [EagleDepth](https://arxiv.org/abs/2610.04554) 和 [PiD 官方代码](https://github.com/nv-tlabs/PiD)。

本次确定的实现为：

> 原始 RGB → 冻结 DVD＋DINO → 预测 depth latent  
> 原始 RGB＋depth latent 条件 → 可训练 PiD＋CPM → 最终深度

PiD 是已有的 latent 条件像素解码器，底层沿用 PixelDiT；并非 EagleDepth 首次提出。原版执行 RGB 生成解码，需要任务适配后才能用于单步深度预测。

用户确认两组共用以下第一阶段权重：

`/mnt/sfs_turbo/DVD/experiments/dino_fourdata_to2500_20261116/training/checkpoint-step-2500/trainer.pt`

该版本使用 Hypersim、VKITTI、TartanAir、RE10K，采用 latent loss，VAE 冻结；不是五数据集版，也不是 pixel decoder 联合微调版。

| 项目 | A：直接预测 | B：残差预测 |
|---|---|---|
| 第一阶段 | 冻结 DVD＋DINO | 相同 |
| PiD 主输入 | 原始 RGB 像素 | 相同 |
| 条件 | 预测 depth latent | 相同 |
| 输出 | 直接输出归一化 log-depth | 粗深度基准＋log-depth 修正量 |
| 粗深度解码 | 无需作为输出基准 | 通过冻结 Wan VAE decoder 得到 |
| 可训练模块 | PiD＋CPM | 相同 |
| 输出头初始化 | 共用预训练初始化 | 未额外零初始化 |

共同配置：

- 每组 **8 卡、每卡 batch 8、global batch 64**，无梯度累积。
- 学习率 **3e-5**，目标 **2500 步**。
- 固定 `t=0.5`，单步预测。
- 损失为 **L1＋2×梯度匹配＋0.5×虚拟法线损失**，监督最终深度。
- 每 500 步全量评测 KITTI、NYUv2、DIODE。
- 残差基准只由模型输出计算，不使用测试 GT 对齐。

CPM 用于缓解 patch 接缝。虚拟法线损失通过深度和相机内参构造三维点并比较表面方向，不需要额外法线标注；其独立收益尚未验证。

关于“是否应该预测残差”，讨论引用了 [PatchRefiner](https://arxiv.org/abs/2406.06679) 的直接／残差消融，以及 SARPN、BetterDepth 等相关工作。外部结果支持残差值得测试，不能替代本框架的实验结论。尤其当前采用 **log-depth 残差且未零初始化输出头**，与此前讨论的零初始化逆深度残差不是同一设置。

#### 4. 数据扩展与 BMVS

用户怀疑 RE10K、DL3DV 的伪深度不准确，要求用：

> VKITTI＋TartanAir＋Hypersim＋BMVS

重新训练，完全排除 RE10K、DL3DV，并从原始 DVD v1.1 初始化，避免继承旧训练影响。

BMVS 深度来自重建网格渲染，仍可能存在缺失和误差，不能等同于无误差的模拟器真值。本组按单图监督使用 BMVS，不将无时间顺序的多视角图像当作连续视频。

数据准备记录：

- 447 个训练场景、50 个保留测试场景。
- 100,131 张有效训练图像，剔除 4 张无效样本。
- 四域等比例采样。
- 训练 DINO adapter＋DiT LoRA，冻结 VAE。
- 云道 8 卡，每卡 batch 4，global batch 32，学习率 1e-5。
- 目标 2500 步，每 500 步全量评测。

用户最终判断为“需要更多数据，但不能盲目加入”。这属于待验证的研究方向，重点应放在数据互补性、标签质量及采样份额变化。

### 尚待验证

- **PiD 是否能超过原 decoder**：继续观察 1000、1500、2500 步，固定同一评测口径，并核对本次冻结基线与历史表格的差异。
- **直接预测还是残差更合适**：当前证据不支持预设残差胜出；零初始化可另做消融，不能混入现有对照。
- **残差表示转换是否可靠**：核对 DVD 逆深度到 log-depth 基准的转换、有效区域及尺度约定，不使用测试 GT 构造基准。
- **14B 是否进入平台或能超过小模型**：等待 2500、3000 步全量评测，结合分域 loss，不能由训练 loss 单独判断。
- **数据质量与采样稀释各占多少影响**：需要同初始化、同累计采样预算、同配比的增删数据对照。
- **pixel loss／decoder 解冻的独立贡献**：缺少从同起点、同预算继续 latent loss 的对照。
- **DIODE 4000 步 RMSE**：待从最终评测文件统一核对。
- **新数据可训练性**：下载完成后还需校验、解压、确认深度／视差单位、内参、有效掩码及场景划分；尚未加入训练。
